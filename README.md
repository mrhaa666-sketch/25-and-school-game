# 25-and-school

剧情向 2D 恐怖解谜 + 追逐同人游戏（非商业）。设计以交接文档为准。

技术栈：TypeScript + Phaser 3 + Vite，后期打包为 Electron Windows 桌面程序。

## 运行

```bash
npm install
npm run dev        # 浏览器打开 http://localhost:5173
npm test           # 周目 / 材料 / 精神值逻辑的单元测试
npm run build      # 类型检查 + 打包到 dist/
```

## 打包成 Windows 桌面版

```bash
npm run dist:win
```

产物在 `release/`：

- `25-and-school-<版本>-portable.exe`：单文件，双击即可运行，不用安装
- `25-and-school-<版本>-win.zip`：解压后运行里面的 `25-and-school.exe`

在 Windows 或 Linux 上都能打包。桌面版里：

- F11 切换全屏
- 存档写在 `%APPDATA%\25-and-school-game\save.json`
- 本地放着的 `assets/sprites/official/` 也会被打包进去（发给别人之前请留意）
- 想换程序图标：放一个 `build/icon.ico`（256×256）再打包

本地调试桌面版：`npm run electron`

## 美术素材

- 图片放在 `assets/` 下，路径和 `docs/art-prompts.md` 一致。缺哪张，游戏里那部分就继续用色块占位，不会报错。
- `assets/sprites/characters/`：GPT 生成的真冬（侧面、爬行、攀绳、晕倒、坐下的背影）和幼年真冬，已提交。
- **官方小人素材不提交**（仓库是公开的），需要在本地放好，用于真冬的正面 / 背面走路和第一幕的三个人：

```
assets/sprites/official/
  mafuyu/{walk_front,walk_back,blink}/01.png …   ← 真冬小人包解压到 mafuyu/ 下
  kanade/  ena/  mizuki/                          ← 25 时小人包直接解压到 official/ 下
```

## 音效

- 放在 `assets/audio/<名字>.ogg`，名字和要找的声音见 **`docs/sound-list.md`**。缺哪个，那里就是安静的。
- 加了文件后重启 `npm run dev`（启动时扫描有哪些音频文件）。
- 用了外部素材，在 `CREDITS.md` 记一行来源和授权。
- 暂停菜单（Esc）里可以关掉声音。

## 目录

```
src/
  core/        状态与纯逻辑：存档、精神值、周目判定、文本查找（不依赖 Phaser，可单测）
  systems/     UI 组件：精神值条、屏幕文字、滤镜、对话框、手机、背包、菜单
  scenes/      场景：标题、UI 层、演出、各幕；flow.ts 管「下一步去哪」
  data/
    cycles/    四个主题周目的差异配置（怪物、考场题目、限定房间……）
    text/      全部台词与 UI 文字（zh-CN.json）
    materials.json  12 份材料
    endings.json    10 个结局
assets/        美术与音效（目前为空，全部是代码画的占位色块）
tests/         单元测试
```

**改文本**：只改 `src/data/text/zh-CN.json`。查找顺序是 `c{主题}.键` → `common.键`，
例如 `c2.act02.wake` 会覆盖二周目的醒来台词，其他周目仍用 `common.act02.wake`。

**说话人**：一行以 `@名字 ` 开头就是这个人说的话，对话框会显示名字牌，例如 `"@真冬 ……大家呢。"`；没有标记的是旁白。
拿到材料时真冬的一句话写在 `materials.<材料ID>` 下，没写就不说。

## 实现约定（作者可改）

- 结局图鉴单独存放（`25-and-school/meta`），「新游戏」不会清空已解锁的结局。
- 读档从存档所在幕的开头继续，不会重复扣进入该幕的 10 点。
- 「本周目」的标记（交过白卷、看过镜子、打过几次电话）在死亡重来时也会重置；材料不会。
- 「第一次打电话不扣」按每次周目开头重新计算。
- 打开手机、背包、暂停时，游戏场景暂停（追逐和停留计时也会停）。
- 第二幕尽头的教室门在追逐战开始前推不开，追逐中才能逃进去。
- 第四幕剪断绳子之前出不了教室。
- 第七幕「停下来听数数声」每停一次只扣一次 5。
- 第九幕「同意 / 不同意」光标默认停在「同意」上。
- 追逐战 2 坚持够 30 秒后，考场门出现，怪物群停下散去；门旁出现垃圾桶（二周目的评语单）——即文档建议的「追逐结束后再调查」。
- 怪物 A：石膏像被看着时不动、背对时速度 215（走 150 / 跑 250）；会动的门平时 120，被看见的瞬间冲刺（出现那一刻不算）；钢琴速度 235，每秒最多转 1.4 弧度。
- 四周目的乐谱：碰到割伤 -5 并被弹开；4 秒内被割 3 次算被追上（结局 4）。
- 「看着」= 真冬面朝怪物的方向（按移动方向判断）。
- 四楼限定房间：美术准备室（二周目）、锁着的教室（三周目，钥匙在医务室药柜）、音乐准备室（四周目），其他周目门锁着。三楼储物柜只在三周目能打开。
- 三、四周目的粉色房间没有人：衣服和被布盖着的镜子放在管道前，调查它就会钻进管道（同时算作看了成员场景）。
- 终周目：不能奔跑、走得慢一点（130）；四楼的限定房间锁着；四楼教室、三楼教室、考场可以走进去看一眼。
- 真结局之后删除存档（结局图鉴保留），回到标题画面。
- 四周目节拍器：每层楼的速度 4F 60 / 3F 80 / 2F 104 / 1F 136 BPM，目前只有画面明灭（音效在 M6）。
