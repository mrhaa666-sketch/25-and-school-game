# 《25时与学校》美术修改文档（给 GPT）

## 一、怎么用这份文档

你要为一款俯视角 2D 恐怖游戏《25时与学校》重画一部分素材、补做一批新素材。场景是深夜的废弃日本学校，气氛是安静、压抑、克制的恐怖，不血腥。

现有素材单张质量可以，问题出在拼到一起之后：物件视角不统一、墙没有立面、没有光、主题装饰被画进了平铺贴图。这份文档的三张清单分别是**保留**、**重画**、**新做**。

工作顺序：

1. 先做第四节里的 `school_desk.png` 和第五节里的 `wall_face_school.png`，各出一张给我确认。这两张定下视角和画风。
2. 确认后，后面每一张都把这两张作为参考图一起带上，保证一致。
3. 按第四节、第五节、第六节的顺序出图。每个文件单独一张图，不要把多个物件拼在一张图里。
4. 每张出完，对照第七节的清单自查，不合格就重出。
5. 文件名必须和文档里写的完全一样，程序按文件名读取。

我会把现有素材一起发给你，都在压缩包的 `references/` 里（目录见第十一节）。标注“保留”的那些是画风参考，尤其是 `blackboard.png`、`window_night.png`、`easel_portraits.png` 这三张，它们的视角和质感是对的。

## 二、统一规范

所有重画和新做的图都要满足这一节，后面的单项说明不再重复。

### 画风

- 手绘厚涂质感，笔触柔和，和现有的 `blackboard.png` 一致。
- 低饱和，冷灰和灰褐为主。物件本身不要画得太暗，游戏里会由程序加黑暗和光照，素材要留出能看清的中间调。
- 光源统一来自左上方，柔光，没有强烈高光。
- 旧、脏、落灰，但不破烂到看不出是什么。
- 不要出现任何人物、文字、水印、边框。需要“有字”的地方（奖状、试卷、乐谱）画成看不清的笔迹。

### 视角（最重要）

统一为**正面 3/4 俯视**：镜头在物件正前方偏上，向下约 45° 看。能看到物件的正面和顶面，左右两个侧面几乎看不到。

- 物件正对镜头，**不要斜着摆**，不要等距视角（菱形底面）。底边要是一条水平线。
- 正交投影，没有近大远小。
- 现有素材里，`bed.png`、`school_desk.png`、`grand_piano.png` 是**错误**的视角（斜 45° 摆放）；`blackboard.png`、`easel_portraits.png` 是**正确**的朝向。
- 地板类和地面贴花类例外：它们是**正上方垂直俯视**。

### 尺寸和背景

| 类别 | 尺寸 | 背景 | 其他 |
| --- | --- | --- | --- |
| 物件 | 512×512 | 透明 | 物件居中，四周留约 5% 空白，底边贴近画布下沿 |
| 墙立面 | 512×768 | 不透明 | 左右无缝衔接，可横向平铺。一张图对应 2 格宽、3 格高 |
| 门 | 512×768 | 透明 | 整扇门连门框画满画布，底边贴画布下沿 |
| 地板、墙顶 | 512×512 | 不透明 | 四向无缝平铺 |
| 地面贴花 | 256×256 | 透明 | 边缘柔和渐隐，低对比 |
| 光效 | 512×512 | 纯黑 #000000 | 用于叠加混合，黑色部分等于透明 |
| 窗外远景 | 2048×1024 | 不透明 | 左右无缝衔接 |
| 过场背景 | 1920×1080 | 见单项说明 | 放在 `ui/bg/` |

- 透明背景必须是真正的透明通道，不要画成棋盘格，也不要留白边或灰边。
- 物件脚下不要画地面，不要画投在地上的阴影，阴影由程序加。
- 物件背后不要带墙的碎块。现有的 `pipe_entrance.png` 带了一块墙，是要改掉的例子。

### 占地比例

游戏用方格地图，每个物件占固定的格数。画的时候宽高比要对得上，否则会被拉伸或显得太小。“宽×深”指占地的格子数，物件的高度向上延伸，不计入。

### 门的特别要求

后墙加高到 3 格之后，门可以画成完整的一扇门。下面六个文件改用 512×768 的竖长画布（`school_gate.png` 例外，见下）：`class_door.png`、`pink_door.png`、`iron_door.png`、`school_gate.png`，以及第五节新做的 `class_door_open.png`、`class_door_leak.png`。

- 画出完整的门：门框、门板、把手、上方的气窗或磨砂玻璃，底部是门槛。
- 门的高度约为 2.4 格，比角色高出约四成。单扇门（教室门、粉门）宽约 1.5 格；`iron_door` 宽约 2 格；`school_gate` 宽约 4 格，这一张画布用 1024×768。

## 十、程序里的用法（画的时候心里有数）

这些不需要你做什么，只是说明图会被怎么用，方便判断画到什么程度：

- 门、墙立面、窗按照**不是正方形**来识别新图：门必须是 512×768（大门 1024×768），墙立面 512×768。旧的 512×512 斜视角图会被忽略。
- 缎带四张的摆法：`01` 从上方垂下来（画在角色前面的前景层）、`02` 系在门把手上（贴墙）、`03` 缠成一团落在地上（正上方俯视）、`04` 拉直横跨（前景层，横跨约 3 格宽）。
- `mafuyu_award_wall.png` 会按 3 格宽画在后墙上；`trophy_case.png`、`plaster_shelf.png`、`sink_row.png` 占 3 格；`bulletin_board.png`、`locker_fallen.png` 占 2 格。
- `lamp_tube.png` 会画在角色前面，透明度 0.5～0.7；灯坏掉或熄灭时由程序压暗。
- 光效图会被转成“亮度 = 透明度”的笔刷，所以只看亮度，颜色会被忽略（终周目的晨光例外，它是直接叠加的）。
- 课桌变体由程序按位置固定挑选，大约三成是变体。
