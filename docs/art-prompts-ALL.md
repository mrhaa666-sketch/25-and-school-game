## 朝向规则（每一张都要遵守）

游戏是从上方往下斜着看的地图，镜头永远在房间的「下方」。所以：

| 类别 | 朝向 |
|---|---|
| 立在地上的物件（课桌、柜子、讲台、人台等） | 正面朝向镜头（朝画面下方）。不侧身、不背对、不斜着摆，底边是水平线。课桌例外：桌面朝画面上方（黑板那边），椅子在靠镜头的一侧，看到椅背 |
| 挂在墙上的东西（画像、公告板、消火栓箱、门牌、窗、门） | 正面平视，正对镜头，没有俯视角度 |
| 落在地上的东西（贴花、落地的缎带、门槛） | 从正上方垂直往下看。门槛：室内在画面上方，门外在画面下方 |
| 人物（Q 版） | 身体正面朝向镜头，左右对称地站着，不侧身、不回头、不背对。只有剧情明确写了「背对」的才背对 |
| 垂下来的东西（绳子、垂下的缎带） | 竖直，上端出画，不打弯、不斜着 |

## 通用前缀 C：CG（正常头身比的插画）

```
【风格硬性规则——每一条都必须遵守】
1. 画风：偏写实的暗色厚涂插画，油画笔触，人物是正常头身比（约 6.5～7 头身）的少女。不是卡通，不是 Q 版，不是赛璐璐，不是 3D 渲染，也不是照片。
2. 人物的脸和五官用细腻的插画画法，但不要描边线稿，边缘靠明暗区分。
3. 角色的发型、发色、眼睛颜色、衣服的款式和颜色，严格照附图和下面「角色外观」的描述，不增加新的配饰、图案或衣服。
4. 色板：整体饱和度很低（不超过 25%）。暗部 #0D0F12～#1C1F24，最亮的地方不超过 #C8C4B8。角色的固有色（头发、衣服）可以保留，但要压暗、偏冷。
5. 光照：只有一个主光源（灯管、月光、窗外的光或黎明的天光，见每条的说明）。画面至少 60% 在阴影里。没有发光、辉光、光晕、镜头光斑。
6. 质感：明显的胶片颗粒和细小噪点，陈旧、积灰。
7. 可怕来自黑暗、空旷和形状的不对劲。不出现血、伤口、尸体、骨头、断肢，不画任何受伤或死亡的身体。
8. 构图：16:9 横构图。画面下方 1/4 保持很暗、没有重要内容（游戏会在那里放对话框）。
9. 输出：只生成一张完整的图。不要拼图、分镜、多视图、边框、文字、签名、水印。

Negative: chibi, super deformed, cartoon, cel shading, flat colors, line art, thick outlines, kawaii, vibrant colors, neon, glow, bloom, lens flare, HDR, 3D render, CGI, photograph, glossy, plastic skin, text, letters, numbers, logo, watermark, signature, frame, border, collage, comic panels, multiple views, blood, gore, wound, injury, corpse, skull, bones, dismemberment
```
