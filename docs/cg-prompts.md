# CG 提示词清单

剧情关键时刻和结局的全屏插画。生成后按「文件」一栏的名字放进 `assets/ui/cg/`，游戏会自动读取。
缺哪张，那一处就照原来的样子显示，不会报错。

- 剧情时刻的 CG：那几句台词出现时铺满画面，对话框盖在 CG 下方，说完淡出回到房间。
- 结局 CG：结局文字页的背景。结局 1、4 的怪物每个周目不同，所以分周目各一张（`_c1`～`_c4`）；只放通用的 `cg_e1` / `cg_e4` 也可以。
- 剧本文字一个字没改，CG 只是在哪句台词出现时显示，登记在代码里。

## 0. 使用说明

### 0.1 CG 前缀（整段复制，放在每条提示词最前面）

```
【风格硬性规则——每一条都必须遵守】
1. 画风：偏写实的暗色厚涂插画，油画笔触，人物是正常头身比（约 6.5～7 头身）的少女。不是卡通，不是 Q 版，不是赛璐璐，不是 3D 渲染，也不是照片。
2. 人物的脸和五官用细腻的插画画法，但不要描边线稿，边缘靠明暗区分。
3. 角色的发型、发色、眼睛颜色、衣服的款式和颜色，严格照附图和下面「角色外观」的描述，不增加新的配饰、图案或衣服。
4. 色板：整体饱和度很低（不超过 25%）。暗部 #0D0F12～#1C1F24，最亮的地方不超过 #C8C4B8。角色的固有色（头发、衣服）可以保留，但要压暗、偏冷。
5. 光照：只有一个主光源（灯管、月光、窗外的光或黎明的天光，见每条的说明）。画面至少 60% 在阴影里。没有发光、辉光、光晕、镜头光斑。
6. 质感：明显的胶片颗粒和细小噪点，陈旧、积灰。
7. 可怕来自黑暗、空旷和形状的不对劲。不出现血、伤口、尸体、骨头、断肢，不画任何受伤或死亡的身体。
8. 构图：16:9 横构图。画面下方 1/4 保持很暗、没有重要内容（游戏会在那里放对话框）。
9. 输出：只生成一张完整的图。不要拼图、分镜、多视图、边框、文字、签名、水印。

Negative: chibi, super deformed, cartoon, cel shading, flat colors, line art, thick outlines, kawaii, vibrant colors, neon, glow, bloom, lens flare, HDR, 3D render, CGI, photograph, glossy, plastic skin, text, letters, numbers, logo, watermark, signature, frame, border, collage, comic panels, multiple views, blood, gore, wound, injury, corpse, skull, bones, dismemberment
```

## 1. 剧情关键时刻（6 张）

### 1.1 `cg_act01_girl.png` 走廊尽头的小女孩

> 出现在：第一幕「走廊尽头站着一个小女孩，背对着这边。」

```
[CG 前缀]
场景：深夜的学校走廊，镜头在走廊这一头，平视，走廊向画面深处延伸，透视很深。两侧是关着的教室门和黑色的窗，窗外没有光。
走廊最远处的尽头，站着一个小学生模样的女孩（真冬小时候，照「真冬（小学）」的外观），背对镜头，面朝尽头的墙，一动不动。她在画面里很小，只占画面高度的 1/6 左右。
光：只有她头顶的一根日光灯亮着，冷白色，把她和她脚下的一小块地面照出来；她和镜头之间的整段走廊都是黑的。
气氛：安静、不该有人在那里。看不到她的脸。
```

### 1.2 `cg_act02_wake.png` 医务室醒来

> 出现在：第二幕开头「医务室。满是灰尘。灯管在闪。」

```
[CG 前缀]
场景：废弃学校的医务室，从床边略高的位置俯视。真冬（高中，照外观）刚从一张旧铁架病床上撑起上半身，头发有点乱，侧脸朝向画面右边，眼神空，还没弄清自己在哪里。
床单发灰，到处是灰尘，空气里飘着细小的灰尘颗粒。旁边有拉了一半的隔帘、锈掉的药柜的一角。
光：天花板上的一根日光灯管在闪，冷白光从上方斜照下来，把病床和她照亮一半，其余是暗的。
构图：人物在画面左中部，占画面高度的 40% 左右。
```

### 1.3 `cg_act04_fall.png` 剪断绳子，它掉了下去

> 出现在：第四幕剪断绳子之后「它摔了下去。」

```
[CG 前缀]
场景：夜里的教室，从窗边向上看。窗外悬着的一根绳子被剪断了，断口还在晃，断掉的那一截正往下坠。
画面上方的黑暗里，一个看不清的巨大形状正在往下掉，只看得到它模糊的轮廓和被窗外月光照到的一点边缘，不画清楚它是什么（不同周目是不同的怪物）。
画面下方是真冬（高中）的一只手，握着一把旧剪刀，在近景里，手和剪刀是暗的剪影。
光：窗外冷色的月光，从画面上方照进来。
不画撞击、碎片飞溅和任何身体。
```

### 1.4 `cg_act07_fork.png` 管道分岔

> 出现在：第七幕「前面分成了两条。」「……那是，我的声音。」

```
[CG 前缀]
场景：狭窄的金属通风管道内部，第一人称视角，贴着管道底部往前看。管道在前方分成上下两条：上面那条完全安静、漆黑；下面那条深处有一点很弱的暖色微光。
画面最下方是真冬（高中）的两只手撑在管道底上（只画手和袖口，浅蓝绿色针织开衫的袖子）。
气氛：幽闭、潮湿、生锈。下面那条管道里好像有人在小声说话，但看不到任何人。
光：只有下面那条管道深处的微光，和真冬手边一点点反光。
```

### 1.5 `cg_act09_choir.png` 它们在唱歌

> 出现在：第九幕「它们在唱歌。」「加入我们吧。」（每个周目都有）

```
[CG 前缀]
场景：音乐室，夜里，从高处俯视。真冬（高中）站在画面中央，周围的空中悬浮着八个黑色的、音符形状的影子（像放大的八分音符，边缘模糊、像烟），一圈绕着她慢慢旋转，像在唱歌。
真冬抬头看着它们，表情很淡，没有害怕的样子。
画面边缘能看到三角钢琴的一角和一排倒着的椅子。
光：窗外冷色的月光，从画面左上方斜照进来，照亮那些音符影子的边缘；地面和角落很暗。
```

### 1.6 `cg_final_outside.png` 校门口的三个人

> 出现在：终周目「门外是校外。凌晨。」「校门口站着三个人。」

```
[CG 前缀，但光照改成：黎明前的天光，天边发白，整体比其它 CG 明亮一些，冷蓝灰色调]
场景：学校大门外，凌晨，天快亮了。镜头在门里面，透过半开的铁门往外看。
门外的路边站着三个人：奏（站在中间，看着门这边，不说话）、绘名（双手抱在胸前，有点不耐烦的样子）、瑞希（朝门这边轻轻挥手）。三个人照各自的外观画，是正常头身比的少女，表情平静。
画面前景是真冬（高中）的背影，一只手搭在门上，正要走出去。
气氛：安静、松了一口气，不恐怖。路灯还亮着，但已经不需要了。
```

