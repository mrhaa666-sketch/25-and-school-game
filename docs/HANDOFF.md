# 交接文档（给接手的人 / AI）

仓库：`mrhaa666-sketch/25-and-school-game`，分支 `main`。游戏用 Phaser 3.90 + TypeScript + Vite 写，打包成 Windows 桌面版用的是 Electron。

## 1. 怎么跑

```bash
npm ci
npm run dev        # 浏览器里玩：http://localhost:5173
npm run dist:win   # 打包 Windows 版，输出在 release/（便携版 exe 和 zip）
npx tsc --noEmit   # 类型检查
```

另外，每次推送到 `main`，GitHub Actions（`.github/workflows/build-win.yml`）会自动打包 Windows 版。打好的包在 Actions 页面那一次运行的 Artifacts 里。

**开发者模式**：所有版本都能用，进游戏后按 F2 打开（笔记本可能要按 Fn+F2）。功能有：
- 修改精神值。
- 领取材料：本周目的材料，或全部 12 份。
- 切换周目。
- 无敌：追逐时不会被抓。
- 跳到第几幕：先在「目标」那一行反复确认，选到要去的幕，再点「跳到第 X 幕」。

## 2. 代码结构（只列最常改的）

| 文件 | 内容 |
|---|---|
| `src/scenes/rooms.ts` | 所有房间的格子地图。字符的含义：`#` 墙，`.` 地板，数字是出口，字母是物件。每个房间还可以写：`decor` 装饰、`lights` 光源、`examine` 一句话的调查点、`chaseGates` 追逐时怪物的绕行点，以及周目之间的布局差异 `cycleLayout` |
| `src/scenes/RoomScene.ts` | 所有房间场景的基类：画墙、地板、门、灯光和黑暗层、前景、遮挡排序；处理移动、调查、鼠标点击、头顶的「F 动作」提示、物件发光、左上角的目标、楼梯间过场、镜子倒影 |
| `src/scenes/Act01~10Scene.ts`、`FinalRunScene.ts` | 每一幕的剧情脚本。子类可以覆盖这几个方法：`objective()` 左上角的目标，`keyTargets()` 要发光的关键物件，`verbFor()` 头顶提示里的动作文字 |
| `src/scenes/flow.ts` | 开始某一幕、结局、周目转场、存档点 |
| `src/data/text/zh-CN.json` | 全部台词。查找顺序是先找 `c{周目}.键`，找不到再找 `common.键` |
| `src/systems/sprites.ts` | 素材清单（每个素材在哪个文件夹、叫什么名字），以及 `CG_MOMENTS`：哪句台词出现时显示哪张 CG |
| `src/systems/Darkness.ts` | 黑暗层和光源 |
| `src/scenes/UIScene.ts` | 对话框、背包、手机、目标栏、「已存档」提示、按键处理 |
| `src/main.ts` | 鼠标左键：在不是自由走动的时候，点一下等于按一次空格 |

**素材**：都在 `assets/` 下，路径和 `sprites.ts` 里的清单一致。缺哪张图，那里就画色块占位，不会报错。

**存档**：每一幕开始时自动存一次档（`GameState.checkpoint`）。死亡结局之后回到最近的存档点。追逐战 1、2 被抓以后，直接回到追逐开始之前（用 `registry` 里的 `retryFrom` 标记来实现）。

## 3. 已经做完的（最近几轮）

- 第一幕改成在校门外；眩晕效果重做了。
- 按键：WASD 移动，Shift 奔跑，F 调查和进门，E 背包，Tab 手机，Esc 暂停，F2 开发者模式。鼠标左键点物件，真冬会自己走过去调查；在剧情、对话、菜单里点左键等于按空格。
- 左上角有「目标」栏。关键物件会发光，并且有光照亮；走近能调查的东西时，它会描一圈边。头顶显示具体的动作，比如「F 拿剪刀」。
- 四楼追逐：护士登场有一段剧情；镜头会转去看开了的逃生门；逃生门有光；靠近门口就算逃进去；被抓后从护士出现之前重来。
- 四楼教室：走到窗边会触发剧情；装饰绳子减少了；打结的小游戏前两次失手可以重来；荡进三楼以后，台词在三楼的画面里说。
- 三楼：镜头转过去、配一道侧光来揭示吊着的绘名；讲台上的剪刀有反光；护士两次往下爬；走廊里那扇门要真冬去查看才会撞开；考场门要真的走到门口才进得去。
- 考场：交卷以后不会再卡在课桌上（P0）。
- 不再显示第几周目。走廊里不画灯管。

## 4. 还没做的（按 GPT 试玩报告整理，按优先级排）

**P1**
- 四楼走廊左右两头长得太像。逃生门应该在玩家第一次路过时就让人记住：给它一块门牌或者窗里透出的光。
- 绳子从四楼荡到三楼：绳子固定在哪、要去哪扇窗、真冬从哪里滚进来，这些在外墙攀爬的插图和三楼的落点之间没有连起来。
- 全游戏的明暗：关键物件、出口、门槛在暗处要保证看得出来。目前只有关键物件发光。
- 三楼走廊的怪物群涌出来：现在是一张 CG 加文字。可以再加门板打开、第一张笑脸卡在门缝这样的分层动画。

**P2**
- 第九幕的选项：「不同意」三秒后会变成「同意」。读得慢的人来不及看完，可以考虑延长阅读时间。（时长是剧情设定，要先问作者）
- 考场：说的是三分钟，但十秒后就出现「交白卷吗？」。另外玩家不能主动交白卷。
- 手机：发消息永远失败，重复打电话还会扣精神值。
- 收集：真结局要集齐 12 份材料，但第一轮玩家很难知道自己漏了什么。
- 设置菜单：亮度、减弱闪光和晃屏、加长限时。
- 背包里显示手上正拿着的关键物品（绳子、剪刀）。

**美术（提示词都在 `docs/art-prompts-fix.md`）**
- 要重出的：`exit_threshold`、`ena_portrait_02`~`06`（一张图只画一幅画像）、`mizuki_ribbon_03`、`decal_test_01/02`。
- 还没做的：`mizuki_mannequin`、`rope_hanging`（目前已经从走廊里去掉了）、`cg_act04_fall`、`cg_act04_ena`、`cg_act04_swarm`、`cg_act01_gate`。

## 5. 不能改的东西（作者定的）

- 剧本的走向、十个结局和它们的触发条件、周目的顺序。
- 精神值的数值，追逐的速度和判定距离。
- 材料的 id 和它们所在的位置，房间 id 和出口编号，存档的结构。
- 不能加规则怪谈式的内容（守则、条目、提示牌）；没有人帮真冬；不能有血腥画面。
- 角色是 Q 版；场景是偏写实的暗色厚涂，不是卡通，不是赛璐璐。CG 里的人物用正常比例。

## 6. 测试方法

`scratchpad` 里有一些 Playwright 脚本，用来跑无头浏览器测试，但它们不在仓库里。最简单的验证方法是：`npm run dev`，然后用 F2 跳到要测的那一幕，开无敌看路线。
